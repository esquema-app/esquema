# Lo que se agrega en la vista previa

Textos ficticios para probar «Agregar» en la vista previa del navegador (sin app ni IA de verdad). `herramientas/generar_demo.py`
los pone en `ui/demo.json` (`agregar`), junto con lo que «responde» la IA (`ejemplos/ia-simulada/<idioma>/agregar.json`).

- `<idioma>/historia.md`: una historia de usuario de Banco Ejemplo (la carpeta de ejemplo).
- `<idioma>/libro.md`: «El faro de Isla Ejemplo», un libro corto inventado para la demo (sin derechos de nadie), con una
  incongruencia a propósito (la edad de Marta) y un cabo suelto (la carta), para que «Revisar incongruencias» tenga qué mostrar.
- `<idioma>/informacion.md`: notas de una reunión con Banco Ejemplo, para «Agregar información»: un flujo nuevo (devoluciones),
  algo que completa el README, algo que cambia la arquitectura (el comprobante lo manda otro servicio) y algo que no calza (la fecha
  de la próxima reunión).
